# BMI、坐标与本地数据说明

本文描述 StatureAtlas 当前实现。相关代码位于 [`src/lib/`](../src/lib/)、[`src/models/record.ts`](../src/models/record.ts) 和 [`src/hooks/`](../src/hooks/)。

## BMI 计算与分类

```text
BMI = 体重（kg）÷ [身高（cm）÷ 100]²
```

| 分类 | 区间 |
| --- | --- |
| 过轻 | BMI < 18.5 |
| 正常 | 18.5 ≤ BMI < 24 |
| 超重 | 24 ≤ BMI < 28 |
| 肥胖 | BMI ≥ 28 |

男女阈值一致。使用未舍入的 BMI 分类，展示时保留一位小数。例如 23.96 显示为 24.0，分类仍为正常。

参考[国家卫生健康委《体重管理指导原则（2024 年版）》](https://www.nhc.gov.cn/wjw/c100378/202412/f3f58b54fbeb4c87b14164fac898bf08.shtml)。适用于中国 18 岁及以上成人，仅供参考，不能替代临床评估。

## 坐标与单位

两张表均为身高 150–190 cm、体重 40–110 kg，步长均为 2，共 21 行 × 36 列。横轴是体重，纵轴是身高。

标记在数据格区域内连续插值，不包含表头和左侧坐标轴：

```text
col = (weightKg - weightMin) / weightStep
row = (heightCm - heightMin) / heightStep
x = (col + 0.5) × cellWidth
y = (row + 0.5) × cellHeight
```

范围边界对应首尾格中心。范围外的合法记录保留在列表中，不生成边缘标记。同性别且身高、体重数值相同的记录聚合显示。

1 公斤 = 2 斤。记录按公斤保存；单位切换仅改变显示和输入换算，不改变 BMI、记录原值或标记坐标。

## 记录约束

- 昵称选填，留空或仅输入空格时自动生成友好名称；保存后的名称为 1–20 个字符。
- 性别为 `male` 或 `female`。
- 身高为 120–220 cm，最多一位小数。
- 体重为 20–300 kg（40–600 斤），精度为 0.05 kg（0.1 斤）。
- 标记颜色为 `blue`、`pink`、`green`、`orange`、`purple` 或 `red`。
- 每条记录包含独立的 UUID、创建时间和更新时间；编辑保留 ID 与创建时间。
- BMI、分类和坐标实时计算，不写入记录。

## 本地存储

| 键 | 内容 |
| --- | --- |
| `height-weight-compare:records:v1` | `{ "version": 1, "records": [...] }` 版本化记录 |
| `stature-atlas:weight-unit:v1` | JSON 字符串 `"kg"` 或 `"jin"` |
| `stature-atlas:guides:female:v1` | 女表辅助线开关，JSON 布尔值 |
| `stature-atlas:guides:male:v1` | 男表辅助线开关，JSON 布尔值 |

记录读取会检查版本、字段、范围和重复 ID。坏 JSON 或未知版本返回空记录并提示；部分记录无效时保留有效记录。存储不可用时保留当前会话的内存操作，并提示记录无法持久保存。

偏好设置异常时使用默认值：公斤、男女辅助线均开启。有效偏好在刷新或重新打开后恢复；标记显示开关仅对当前会话生效。

记录与偏好仅保存在当前浏览器，无云同步、备份或导入导出。清理站点数据、使用无痕模式或更换设备可能导致数据丢失。BMI 计算器的输入不保存为记录。
